# Quick

![macOS 14+](https://img.shields.io/badge/macOS-14%2B-black)
![Swift 6](https://img.shields.io/badge/Swift-6-orange)
![Apple Silicon](https://img.shields.io/badge/Apple%20Silicon-native-blue)

Минималистичный менеджер скриншотов для Mac. Наводишь мышь на чёлку - выезжает
шторка с последними скриншотами. Клик, и скриншот в буфере: вставляй куда угодно.
Ходить на Рабочий стол не нужно!! 

Так как я часто использую в своей работе скриншоты, то меня сильно выбешивает постоянно их выискивать на рабочем столе и переключаться, теряя на этом время. Я искал решения, которые могут мне с этим как-то помочь. Пробовал бесплатные и платные. Не приживались. Либо неудобные, либо перегруженные функциями, либо не заходили по дизайну.
Так появился Quick - быстрый, минималистичный и не делающий ничего лишнего.

## Установка

1. Скачайте `Quick-1.1.dmg` из [релизов](https://github.com/helpsolution/quick/releases)
   и перетащите приложение в «Программы».
2. **Первый запуск — правым кликом по иконке → «Открыть».** Приложение подписано
   ad-hoc, поэтому обычный двойной клик Gatekeeper остановит. Подтвердить нужно
   один раз.
3. Разрешите доступ к папке Рабочий стол, когда система спросит.

## Как пользоваться

| Действие           | Что происходит                                    |
|--------------------|---------------------------------------------------|
| Клик по миниатюре  | Скриншот в буфере: и картинкой, и файлом          |
| ⌘-клик, Shift-клик | Выбрать несколько                                 |
| Перетаскивание     | Переносит файлы прямо в приложение                |
| Правый клик        | Открыть, показать в Finder, переместить в корзину |
| «…» в углу шторки  | Настройки и выход                                 |

Шторка не забирает фокус: после клика можно сразу жать ⌘V там, где работали.
Скриншоты остаются на месте — приложение только читает папку. Она берётся из
системной настройки снимков экрана, а если не задана — Рабочий стол.

## Статистика

В настройках есть кнопка «Статистика»: сколько раз выезжала шторка, сколько
скриншотов скопировано и перетащено, как это распределено по часам, дням
и месяцам.

Считаются только числа — ни имён файлов, ни самих изображений. Данные лежат
в `~/Library/Application Support/Quick/` и никуда не отправляются: у приложения
нет ни сетевого кода, ни сервера. Сбор отключается тумблером, рядом — кнопка
«Удалить данные».

## Сборка

```bash
./scripts/build.sh --install    # собрать и поставить в /Applications
./scripts/release.sh            # собрать DMG для релиза
```

Требуется Swift 6 из Xcode 15 и новее.
