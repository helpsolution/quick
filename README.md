# Quick

Минималистичный менеджер скриншотов(возможно еще будет история копипастов) для Mac. Наводишь мышь на челку и из нее выезжает шторка с последними скриншотами.
Клик и скриншот в буфере, вставляй куда угодно. Ходить на Рабочий стол не нужно. Так как я часто использую в своей работе скриншоты, то меня сильно выбешивает постоянно их выискивать на рабочем столе и переключаться, теряя на этом       
время. Я искал решения, которые могут мне с этим как-то помочь. Пробовал бесплатные и платные. Не приживались. Либо неудобные, либо перегруженные функциями, либо не заходили по дизайну. 
Так появился Quick - быстрый, минималистичный и не делающий ничего лишнего.

## Как это устроено

- **Никакого окна в Dock и в строке меню.** Приложение — фоновый агент (`LSUIElement`).
- **Триггер — упор в верхнюю кромку.** Шторка выезжает, только когда курсор
  уперся в самый верх экрана в пределах челки — полоса в 3 pt. Вся высота челки
  не годится: по строке меню курсор ходит постоянно, и шторка выскакивала бы
  посреди обычной работы. Строка меню при этом остаётся кликабельной — окно
  панели уходит с экрана, пока шторка закрыта.
- **Фокус не воруется.** Окна — `nonactivatingPanel`, активное приложение остаётся
  активным, поэтому после клика можно сразу жать ⌘V в том же окне, где работал.
- **Скриншоты не переносятся.** Приложение только читает папку, файлы остаются на месте.
- **Слежение без polling.** `DispatchSource` на дескрипторе папки: новый скриншот
  появляется в шторке сразу после сохранения.
- **Миниатюры через ImageIO.** Downsampling прямо из файла, с кэшем в памяти —
  быстрее Quick Look и без лишней памяти.
- **Картинка в буфер отдаётся лениво.** `NSPasteboardItemDataProvider` читает
  файл только когда приёмник вставки действительно просит PNG. Иначе каждый клик
  при множественном выборе перечитывал бы все выбранные файлы целиком.

Папка берётся из системной настройки `com.apple.screencapture location`,
а если она не задана — `~/Desktop`.

## Действия

| Действие                | Что происходит                                       |
|-------------------------|------------------------------------------------------|
| Клик по миниатюре       | Скриншот в буфере (как картинка и как файл)          |
| ⌘-клик                  | Добавить скриншот к выбранным или убрать из них      |
| Shift-клик              | Выбрать диапазон от последнего выбранного            |
| Перетаскивание          | Файл переносится прямо в приложение                  |
| Правый клик             | Открыть, показать в Finder, переместить в корзину    |
| «…» в углу панели       | Папка скриншотов, настройки, выход                   |

Буфер заполняется в двух представлениях сразу: PNG вставится картинкой в редактор
или мессенджер, file URL — файлом в Finder или в поле загрузки.

Выбранные скриншоты помечены галочкой — других индикаторов нет намеренно.
Выбор живёт в отдельном `SelectionStore`, а не в состоянии панели:
наблюдатель SwiftUI инвалидируется на любое изменение объекта, поэтому общий
объект заставлял каждый клик перестраивать всю панель вместе с AppKit-слоями
ячеек — 26 мс процессорного времени на клик против 19 мс сейчас. Буфер обновляется на каждом клике, отдельной команды «скопировать» нет.
Выбор сбрасывается, когда шторка закрывается. Порядок в буфере — как на экране.

Приёмник решает сам, что делать с несколькими элементами: Finder и мессенджеры
вставят все файлы, а редактор, умеющий только одну картинку, возьмёт первую.

Перетаскивание следует тому же правилу, что и Finder: тянешь за выбранный —
переносятся все выбранные, тянешь за невыбранный — только он. SwiftUI-модификатор
`.onDrag` отдаёт ровно один элемент, поэтому мышиный слой ячейки сделан на
AppKit (`DragSelectionView`) — там `beginDraggingSession` умеет много файлов
сразу. Этот же слой ведёт клик и рисует подсветку наведения прямо в `CALayer` —
через SwiftUI каждое пересечение границы ячейки перерисовывало бы ячейку вместе
с её `NSView`.

Порядок модификаторов в ячейке важен: `.clipped()` и `.clipShape()` до `overlay`
ломают позиционирование AppKit-слоёв — все получают один и тот же frame и
ложатся друг на друга, после чего кликается только первая миниатюра.

## Установка

Скачайте `Quick-<версия>.dmg` из релизов, откройте и перетащите приложение
в «Программы».

**Первый запуск — через правый клик по иконке → «Открыть».** Обычный двойной
клик покажет предупреждение «Apple не может проверить приложение»: сборка
подписана ad-hoc, без платного Developer ID, поэтому Gatekeeper требует
подтверждения. Один раз подтвердили — дальше запускается как обычно.

Затем macOS спросит доступ к папке Рабочий стол — без него шторка покажет
подсказку вместо скриншотов. Выдать доступ позже: Системные настройки →
Конфиденциальность и безопасность → Файлы и папки → Quick.

## Настройки

Шторка → «…» → «Настройки…». Внутри только необходимое: автозапуск при входе,
путь к папке со скриншотами и версия.

Это единственное окно, которое забирает фокус: переключателям и кнопкам нужно
активное приложение, тогда как шторка фокус не берёт принципиально. После
закрытия настроек фокус возвращается туда, где вы работали.

Папку задаёт сама macOS, менять её из Quick нельзя намеренно — иначе
приложение молча переписывало бы системную настройку снимков экрана.

## Сборка

Xcode открывать не нужно, всё из терминала:

```bash
./scripts/build.sh              # собрать в ./build/Quick.app
./scripts/build.sh --run        # собрать и запустить
./scripts/build.sh --install    # собрать, поставить в /Applications и запустить
./scripts/release.sh            # собрать dist/Quick-<версия>.dmg для релиза
swift scripts/make-icon.swift   # перерисовать Resources/AppIcon.icns
```

Требуется Swift 6 (входит в Xcode 15+). Иконка не лежит в репозитории картинкой,
а рисуется кодом — правится там же, в `scripts/make-icon.swift`.

Ad-hoc подпись меняется при каждой пересборке, поэтому после `build.sh` система
спросит доступ к папке заново. Пользователей готового DMG это не касается —
они приложение не пересобирают.

Если появится Developer ID, релиз собирается без предупреждений Gatekeeper:

```bash
QUICK_SIGN_IDENTITY="Developer ID Application: Имя (TEAMID)" ./scripts/release.sh
xcrun notarytool submit dist/Quick-<версия>.dmg --keychain-profile <профиль> --wait
xcrun stapler staple dist/Quick-<версия>.dmg
```

## Структура

```
Resources/                           Info.plist и иконка
scripts/                             сборка .app, релизный DMG, генератор иконки
Sources/Quick/
  Main.swift, AppDelegate.swift      точка входа, фоновый агент
  Notch/                             геометрия челки, окна, отслеживание наведения
  Screenshots/                       папка, слежение за ней, миниатюры
  UI/                                SwiftUI-панель, карточки, окно настроек
  Support/                           буфер обмена, действия с файлами, автозапуск
```
